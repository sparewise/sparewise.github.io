Disk Cleanup or Storage Sense?

Short answer: Both are Windows' own tools. Disk Cleanup removes system leftovers once, when you run it. Storage Sense runs by itself on a schedule and clears temporary files and, if you allow it, the Recycle Bin and old Downloads. Neither looks at app caches like browsers, chat apps or developer tools.

By hand, with Windows' own tools

  1. Disk Cleanup: press Win+R, type cleanmgr, choose C:, then Clean up system files for Windows Update leftovers.
  2. Storage Sense: open Settings > System > Storage > Storage Sense, turn it on and choose how often it runs and what it may remove.
  3. Check the Downloads option carefully: it removes files you have not opened for the chosen time.

Questions

Should I use both?

Storage Sense for regular tidying, Disk Cleanup now and then for update leftovers. They do not conflict.

Is Disk Cleanup going away?

Microsoft has moved most of it into Settings > Storage, but cleanmgr still works on Windows 11.

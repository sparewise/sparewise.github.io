Where Ollama stores models on Windows

Short answer: in %USERPROFILE%\.ollama\models. Each model is several gigabytes, and the files have hash names, so Explorer cannot tell you which model is which.

By hand

  1. See your models and sizes: ollama list
  2. Remove one you no longer use: ollama rm <name>. Do not delete files under blobs yourself: models share layers, and a missing one breaks other models.
  3. To keep models on another drive, set the OLLAMA_MODELS environment variable to a folder there and restart Ollama.

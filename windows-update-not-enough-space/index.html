Windows Update says there is not enough space

Short answer: Windows Update needs room to download and unpack updates, often 10 to 20 GB for a feature update. Free space with caches, temporary files and old update files first. Do not delete anything inside C:\Windows by hand.

By hand, with Windows' own tools

  1. Run Settings > System > Storage > Cleanup recommendations.
  2. Remove Previous Windows installation(s) if you no longer plan to go back to the old version.
  3. Empty the Recycle Bin and remove old installers from Downloads.
  4. Connect a USB drive: Windows Update can use it for temporary space.

Questions

How much space does a Windows 11 update need?

Monthly updates need a few GB. A feature update can need 10 to 20 GB free.

Can I delete the SoftwareDistribution folder?

Not by hand while updates run. Use Cleanup recommendations, which removes old update files safely.

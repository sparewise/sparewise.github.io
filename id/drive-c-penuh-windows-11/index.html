Drive C: penuh di Windows 11? Cara mengosongkan ruang dengan aman

Jawaban singkat: Sebagian besar drive C: yang penuh berisi cache yang terbentuk lagi sendiri, sisa Windows Update, file hibernasi, installer lama di Downloads, dan data aplikasi besar seperti game atau model AI. Bersihkan itu dulu. Jangan pernah menghapus folder di dalam C:\Windows atau Program Files secara manual.

Manual, dengan alat bawaan Windows

  1. Buka Settings > System > Storage untuk melihat apa yang paling besar.
  2. Nyalakan Storage Sense dan jalankan Cleanup recommendations untuk file sementara dan file update lama.
  3. Kosongkan Recycle Bin: file yang dihapus tetap memakai ruang sampai dikosongkan (periksa dulu, tidak bisa dibatalkan).
  4. Hapus aplikasi yang tidak dipakai di Settings > Apps > Installed apps.

Dengan Sparewise

  • Pindai satu menit menunjukkan drive per bagian: yang terbentuk lagi sendiri, yang bisa diunduh lagi, Windows, dan yang hanya ada di PC Anda.
  • Menjelaskan setiap item dan apakah aman dihapus, dengan kata-kata sederhana.
  • Tidak ada yang berubah sampai Anda setuju, dan yang dihapus masuk Recycle Bin atau disisihkan 14 hari.

Pertanyaan

Amankah menghapus file dari drive C:?

Cache, file sementara, dan sisa Windows Update aman. File di C:\Windows, Program Files, dan dokumen Anda tidak.

Kenapa drive C: penuh padahal saya tidak menyimpan apa-apa?

Aplikasi dan Windows mengisinya sendiri: cache browser dan aplikasi, unduhan update, file hibernasi, cache game, dan alat seperti Docker atau model AI.

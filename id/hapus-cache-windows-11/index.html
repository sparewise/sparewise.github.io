Cara menghapus cache di Windows 11 (dan apa yang aman dihapus)

Jawaban singkat: Cache adalah salinan yang disimpan aplikasi agar lebih cepat terbuka. Cache terbentuk lagi sendiri, jadi aman dihapus, tetapi akan tumbuh lagi seiring pemakaian. Yang terbesar biasanya cache browser, file sementara Windows, cache thumbnail, dan cache game.

Manual, dengan alat bawaan Windows

  1. File sementara: Settings > System > Storage > Temporary files, centang yang ingin dihapus lalu klik Remove files.
  2. Cache browser: di Edge atau Chrome buka Settings, Privacy, Clear browsing data, dan centang hanya cached images and files, agar kata sandi dan riwayat tetap ada.
  3. Cache Microsoft Store: tekan Win+R, ketik wsreset.exe lalu Enter.

Dengan Sparewise

  • Menemukan semua cache di PC sekaligus, per aplikasi, dengan ukurannya.
  • Menandai mana yang terbentuk lagi sendiri dan mana yang sebaiknya disimpan.
  • Menghapus yang Anda setujui, ke Recycle Bin.

Pertanyaan

Amankah menghapus cache di Windows 11?

Ya. Cache akan terbentuk lagi. Aplikasi mungkin sedikit lebih lambat saat pertama dibuka.

Apakah menghapus cache browser menghapus kata sandi?

Tidak, jika Anda hanya mencentang "Cached images and files".

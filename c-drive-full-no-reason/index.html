C: drive full, but you cannot see why?

Short answer: File Explorer hides some of the biggest space users: the hibernation file, the page file, System Restore points, the Recycle Bin, old Windows updates, and virtual disks from Docker or WSL. A tool that sizes every folder shows where it went.

By hand, with Windows' own tools

  1. Empty the Recycle Bin after checking it: deleted files still use space until you do.
  2. Open Settings > System > Storage and check Temporary files and System & reserved.
  3. Check for Windows.old after an upgrade; see Windows.old.
  4. If you use Docker or WSL, their virtual disks grow and do not shrink by themselves; see Docker and WSL.

Questions

Why does File Explorer show less than the drive uses?

It hides system files and does not count some protected folders. A drive map that reads every folder shows them.

Could it be a virus?

Rarely. Most unexplained space is Windows files, caches or virtual disks. Run Windows Security if you are unsure.

Every folder Sparewise knows

107 folders on Windows. 62 are offered for clearing, because the program that made them rebuilds them when needed. The rest are reported so you know what they are, and Sparewise never removes them.

This list is generated from the same rules the app uses, so it is exactly what Sparewise does. Anything it offers goes to the Recycle Bin, never deleted permanently. See also how it decides what is safe.

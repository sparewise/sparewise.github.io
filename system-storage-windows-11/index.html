Why is "System & reserved" so big?

Short answer: System & reserved is Windows itself plus a few large helper files: the hibernation file, the page file, System Restore points and space Windows keeps free for updates. Windows itself should stay. The helper files can often be made smaller with Windows' own settings.

By hand, with Windows' own tools

  1. Open Settings > System > Storage and select System & reserved to see the parts: system files, virtual memory, hibernation file, System Restore, reserved storage.
  2. Hibernation file: if you never use Hibernate, open Terminal (Admin) and run powercfg /hibernate off. Fast Startup also stops. powercfg /hibernate on brings both back.
  3. System Restore: open Create a restore point from Start, select the C: drive, Configure, and lower the maximum usage. Fewer restore points are kept.
  4. Virtual memory (page file): leave it on. You can move it to another drive; see pagefile.sys.
  5. Reserved storage: Windows keeps this free so updates can install. Leave it.

Questions

Can I delete files from System & reserved?

Not by hand. Deleting Windows files can stop Windows from starting. Use Windows' own settings described above.

Why did System & reserved grow after an update?

Windows keeps the previous version and update downloads for a while. See Windows.old and Windows Update leftovers.

¿Disco C: lleno en Windows 11? Cómo liberar espacio con seguridad

Respuesta corta: La mayor parte de un disco C: lleno son cachés que se regeneran solas, restos de Windows Update, el archivo de hibernación, instaladores viejos en Descargas y datos grandes de apps, como juegos o modelos de IA. Libera eso primero. Nunca borres a mano carpetas dentro de C:\Windows o Archivos de programa.

A mano, con las herramientas de Windows

  1. Abre Configuración > Sistema > Almacenamiento para ver qué ocupa más.
  2. Activa Sensor de almacenamiento y usa Recomendaciones de limpieza para archivos temporales y de actualizaciones antiguas.
  3. Vacía la Papelera de reciclaje: los archivos borrados siguen ocupando espacio hasta que lo hagas (revísala antes, no se puede deshacer).
  4. Desinstala las apps que ya no usas en Configuración > Aplicaciones > Aplicaciones instaladas.

Preguntas

¿Es seguro borrar archivos del disco C:?

Las cachés, los archivos temporales y los restos de Windows Update sí. Los archivos de C:\Windows, Archivos de programa y tus documentos, no.

¿Por qué se llena el disco C: si no guardé nada?

Las apps y Windows lo llenan solos: cachés del navegador y de apps, descargas de actualizaciones, el archivo de hibernación, cachés de sombreadores de juegos y herramientas como Docker o modelos de IA.

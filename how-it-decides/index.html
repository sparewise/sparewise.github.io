How Sparewise decides what is safe to clear

Short answer: not by file type or by guessing. Sparewise only offers to clear folders it knows by exact location, each with a written, tested reason why it rebuilds by itself. Everything else is reported, never removed.

What it offers to clear

  • Caches at known locations: npm, pnpm, Yarn, pip, uv, NuGet, Gradle, Maven, Cargo, Go, browser and editor caches, Windows temporary files and more.
  • Each has a rule saying why it comes back by itself (the tool that made it downloads or rebuilds it when needed). The rules are covered by automated tests.
  • No AI decides this. An assistant connected over MCP can suggest and plan, but the verdict is always the tested rule.

What it never removes

See every folder it knows, with its verdict →

  • AI models (Ollama, LM Studio, Hugging Face): slow to download again. It reports size, last use, shared layers and old revisions, and gives you the command to remove one.
  • Docker volumes, WSL distributions, virtual machines: they can hold your data. It shows the size and the right tool's command.
  • Your own files: large videos, duplicates and old downloads are listed so you can decide. Sparewise does not remove them.
  • Any folder you add to the exclusions in Settings.

Checks before every change

  1. The plan is shown to you first, with sizes. Nothing changes until you confirm (or, for an AI assistant, unless your own limits allow it).
  2. Right before each step runs, it is checked again: the path must still be exactly the known location, and the rule must still hold. If not, that step is refused.
  3. Files a program has open are left where they are, and it tells you, so you can close the program and try again.
  4. Everything goes to the Recycle Bin or an undo window. If the Recycle Bin is turned off or too small for an item, Sparewise refuses rather than deleting.
  5. Afterwards it measures how much space was really freed.

AI assistants

Over MCP an assistant gets the same rules plus your own limits: a size cap, which kinds of change it may make alone, and folders it must never touch. It can never delete permanently, and every change it makes is recorded with its name and reason and can be undone.

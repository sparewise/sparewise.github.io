Deleted files but got no space back?

Short answer: Deleted files go to the Recycle Bin and keep using space until it is emptied. Other causes: System Restore points, a file still open in a program, or the space belongs to a different drive.

By hand, with Windows' own tools

  1. Empty the Recycle Bin (look first: emptying cannot be undone).
  2. Close the program that had the file open, then check again.
  3. System Restore points: System Properties > System Protection > Configure to see and limit their space.

Questions

Does deleting a file free space immediately?

Only after the Recycle Bin is emptied, or if you used Shift+Delete.

Where did my free space go?

Often to caches and app data that grow by themselves. A storage analyzer shows which.

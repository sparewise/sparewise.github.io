The WinSxS folder is huge: can you shrink it?

Short answer: WinSxS holds the Windows components that updates and repairs need. Never delete files from it by hand. Explorer overstates its size, because many files in it are also used from other places (hard links). Windows has its own command to remove old, replaced components.

By hand, with Windows' own tools

  1. Open Terminal as administrator.
  2. See its real size: Dism.exe /Online /Cleanup-Image /AnalyzeComponentStore
  3. Remove old component versions: Dism.exe /Online /Cleanup-Image /StartComponentCleanup

With Sparewise

  • Shows WinSxS as part of Windows itself, not as something to delete.
  • Points to the Windows command instead of touching system files.

Questions

Can I delete the WinSxS folder?

No. Windows needs it for updates and repairs, and deleting it can break the PC. Use the DISM cleanup command.

Why does WinSxS look so big?

Explorer counts files that are shared with the rest of Windows, so the real extra space is usually much smaller.

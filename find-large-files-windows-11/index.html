How to find large files on Windows 11

Short answer: File Explorer can search by size; a drive map shows every folder by size so you can see where big files are. Big files are often videos, old installers, disk images and game files. Decide case by case: move what you want to keep, remove what you no longer need.

By hand, with Windows' own tools

  1. In File Explorer, open the drive and search for size:gigantic (over 4 GB) or size:huge (1 to 4 GB).
  2. Sort the results by Size.
  3. Check Downloads for old installers (.exe, .msi) and disk images (.iso).
  4. Move photos and videos you want to keep to another drive or cloud storage before removing anything.

Questions

Is it safe to delete large files?

Only files you know you do not need. Programs and games should be removed with their own uninstaller, not by deleting their files.

What are .iso and .vhdx files?

.iso files are disk images, often installers. .vhdx files are virtual disks used by WSL, Docker or Hyper-V; do not delete them while in use.

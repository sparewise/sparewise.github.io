How to clear cache on Windows 11

Short answer: Caches are copies apps keep to load faster. They rebuild by themselves, so clearing them is safe, but they grow back with use. The biggest are usually browser caches, Windows temporary files, thumbnail cache, game shader caches and developer package caches (npm, pip, NuGet).

By hand, with Windows' own tools

  1. Temporary files: Settings > System > Storage > Temporary files, tick what to remove, then Remove files.
  2. Browser cache: in Edge or Chrome open Settings, Privacy, Clear browsing data, and tick only cached images and files, so passwords and history stay.
  3. Thumbnail cache: it is one of the options in Temporary files.
  4. Microsoft Store cache: press Win+R, type wsreset.exe, Enter.

Questions

Is it safe to clear cache on Windows 11?

Yes. Caches rebuild themselves. Apps may load a little slower the first time afterwards.

Will clearing the browser cache delete my passwords?

Not if you tick only "Cached images and files". Passwords, cookies and history are separate options.

How often should I clear cache?

Only when you need space. Clearing often gives little, because caches grow back.

C: drive full on Windows 11? Free up space, step by step

Short answer: Most of a full C: drive is caches that rebuild themselves, Windows Update leftovers, the hibernation file, old installers in Downloads, and big app data such as games or AI models. Clear those first. Never delete folders inside C:\Windows or Program Files by hand.

By hand, with Windows' own tools

  1. Open Settings > System > Storage to see which categories are biggest.
  2. Turn on Storage Sense there, and run Cleanup recommendations for temporary files and old update files.
  3. Empty the Recycle Bin: deleted files still use space until you do (look first, this cannot be undone).
  4. Uninstall apps you no longer use in Settings > Apps > Installed apps.
  5. Move large personal files (videos, photos) to another drive or to OneDrive set to keep files online only.

Questions

Is it safe to delete files from the C: drive?

Caches, temporary files and Windows Update leftovers are safe to clear because they rebuild or are no longer needed. Files inside C:\Windows, Program Files and your own documents are not. Use Windows Storage settings or a tool that explains each item.

Why is my C: drive full when I did not save anything?

Apps and Windows fill it on their own: browser and app caches, update downloads, the hibernation file, game shader caches, and developer or AI tools such as Docker and local models.

How much free space does Windows 11 need?

Keep at least 20 to 30 GB free so Windows Update can install and the PC stays responsive.

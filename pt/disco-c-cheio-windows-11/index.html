Disco C: cheio no Windows 11? Como liberar espaço com segurança

Resposta curta: A maior parte de um disco C: cheio são caches que se refazem sozinhos, sobras do Windows Update, o arquivo de hibernação, instaladores antigos em Downloads e dados grandes de apps, como jogos ou modelos de IA. Libere isso primeiro. Nunca apague à mão pastas dentro de C:\Windows ou Arquivos de Programas.

Manualmente, com as ferramentas do Windows

  1. Abra Configurações > Sistema > Armazenamento para ver o que ocupa mais.
  2. Ative o Sensor de Armazenamento e use as Recomendações de limpeza para arquivos temporários e atualizações antigas.
  3. Esvazie a Lixeira: arquivos apagados ainda ocupam espaço até você fazer isso (confira antes, não dá para desfazer).
  4. Desinstale apps que não usa em Configurações > Aplicativos > Aplicativos instalados.

Perguntas

É seguro apagar arquivos do disco C:?

Caches, arquivos temporários e sobras do Windows Update, sim. Arquivos em C:\Windows, Arquivos de Programas e seus documentos, não.

Por que o disco C: enche se eu não salvei nada?

Apps e o Windows enchem sozinhos: caches do navegador e de apps, downloads de atualizações, o arquivo de hibernação, caches de jogos e ferramentas como Docker ou modelos de IA.

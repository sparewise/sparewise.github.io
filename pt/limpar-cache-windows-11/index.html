Como limpar o cache no Windows 11 (e o que é seguro limpar)

Resposta curta: Caches são cópias que os apps guardam para abrir mais rápido. Eles se refazem sozinhos, então limpar é seguro, mas voltam a crescer com o uso. Os maiores costumam ser os do navegador, os arquivos temporários do Windows, o cache de miniaturas e os caches de jogos.

Manualmente, com as ferramentas do Windows

  1. Arquivos temporários: Configurações > Sistema > Armazenamento > Arquivos temporários, marque o que quiser e clique em Remover arquivos.
  2. Cache do navegador: no Edge ou Chrome abra Configurações, Privacidade, Limpar dados de navegação, e marque só imagens e arquivos em cache, para manter senhas e histórico.
  3. Cache da Microsoft Store: pressione Win+R, digite wsreset.exe e Enter.

Perguntas

É seguro limpar o cache no Windows 11?

Sim. Os caches se refazem. Os apps podem demorar um pouco mais na primeira vez.

Limpar o cache do navegador apaga minhas senhas?

Não, se você marcar só "Imagens e arquivos em cache".

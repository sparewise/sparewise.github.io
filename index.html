How it decides

Built to be trusted with your disk.

Nothing is removed on a guess, and nothing is removed without you. You always see what will happen, and you can always undo it.

Rebuilds by itself

Caches, temp files, build output. Offered: the tool that made them rebuilds them.

Can be downloaded again

AI models, SDKs, games. Shown with size and last use; removed with its own tool, by you.

Exists only here

Your photos, videos and documents. Reported so you can decide; never removed by Sparewise.

For AI agents

Your coding agent can free space. Within your limits.

Sparewise is an MCP server. Claude, Codex, Cursor and VS Code can ask why the drive is full and plan a cleanup. They apply it only under the policy you set, nothing they do is permanent, and every change is recorded with their name and reason.

Questions

Good to know

Is it free?

Yes, everything is free today, with no account and no ads. Later versions may add paid features; anything you already have keeps working.

Does it send anything anywhere?

No. No telemetry, no analytics, no account. It checks GitHub for updates and reaches only what you ask it to. See the privacy page.

Why does Windows warn when I run the installer?

It is new and not code-signed yet. The Microsoft Store copy installs with no warning. With the installer, choose More info, then Run anyway.

Mac or Linux?

Windows 10 and 11 for now. The command line also runs on macOS and Linux.

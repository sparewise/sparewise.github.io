How it decides

Built to be trusted with your disk.

No AI decides what is deleted. Every verdict is a written rule, covered by automated tests, and checked again the moment it runs.

  1. Scanning changes nothingIt only reads sizes and dates, without disturbing when you last used a file.
  2. You see the plan firstExact folders and sizes, and why each one comes back by itself.
  3. Checked again, right beforeStill the same known location, still safe. If not, that step is refused.
  4. Everything can be put backTo the Recycle Bin or an undo window. Then it measures what was really freed.

For AI agents

Your coding agent can free space. Within your limits.

Sparewise is an MCP server. Claude, Codex, Cursor and VS Code can ask why the drive is full and plan a cleanup. They apply it only under the policy you set: a size cap, the kinds of change allowed, folders never touched. Nothing an agent does is permanent, and every change is recorded with its name and reason.

Connect your agent
terminal
# Claude Code
claude mcp add sparewise -- npx -y sparewise mcp

# policy.json: what an agent may do alone
{
  "allowUnattendedReversible": true,
  "maxUnattendedBytes": 21474836480,
  "unattendedActions": ["clean-junk", "cache-unused"],
  "excludedPaths": ["C:\\work\\**\\keep-*"]
}

Questions

Good to know

Is it free?

Yes, everything is free today, with no account and no ads. Later versions may add paid features; anything you already have keeps working.

Does it send anything anywhere?

No. No telemetry, no analytics, no account. It checks GitHub for updates, and only reaches what you ask it to. See the privacy page.

Why does Windows warn when I run the installer?

It is new and not code-signed yet. The Microsoft Store copy installs with no warning. With the installer, choose More info, then Run anyway.

Mac or Linux?

Windows 10 and 11 for now. The command line also runs on macOS and Linux.

See why your drive is full.
Free space safely.

Sparewise finds the space that developer and AI tools quietly fill (package caches, local AI models, Docker and WSL disks) plus ordinary Windows clutter. It tells you what each item is, frees it only when you say so, and can put back anything it moved.

Free · Windows 10 and 11 · x64 and ARM · No admin rights · No account · No telemetry

One clear answer

"Why is my drive full?" The drive in plain parts: what rebuilds itself, what can be downloaded again, and what exists only on this PC.

A full check in half a minute

Caches, AI models, apps, Windows files, disk health, startup programs, updates, memory and speed, then one list of what is worth doing. It starts by itself the first time.

AI models, without commands

Ollama, Hugging Face, LM Studio, ComfyUI, Forge and more, one by one with when each was last used. Remove a Hugging Face or LM Studio model with one button; it goes to the Recycle Bin.

"Free 20 GB"

Picks the smallest set of safe caches that reaches your goal, and asks once.

Undo for everything

What Sparewise removes goes to the Recycle Bin or an undo window, so it can be put back. (Windows' own Disk Cleanup, which it can start for update leftovers, deletes permanently and asks first.)

Honest results

It measures what was really freed. Files a program has open stay where they are, and it tells you.

Only in Sparewise

Keep what you use, clear what you don't

Most of a package cache is old versions nothing uses. Sparewise shows that part (7.7 GB on one developer PC) and clears just it, so your next install doesn't download everything again.

AI models stored once

The same model in Ollama and LM Studio takes the space twice. Store once keeps one copy for both programs. Nothing is deleted.

Sees inside WSL

From Windows, WSL is one big file. Sparewise lists the npm, pip, apt and model caches inside it, with the command that clears each.

Frees the cheapest space first

Asked for 20 GB, it takes what comes back by itself without downloading before anything your next build would fetch again.

Packages you keep twice

The same npm package in 18 projects, the same Python library in 14 environments. Sparewise measures what pnpm or uv would save: 5 GB on one developer PC.

Hibernate old projects

A project you have not touched in months becomes one archive without node_modules or build folders, checked file by file before the original goes to the Recycle Bin. Open the archive to bring it back.

Leftovers no other cleaner sees

Old editor extensions VS Code, Cursor and Windsurf keep after updates (1 GB on one PC), installers apps keep after updating themselves, and git history waiting to be packed.

Knows what is yours

A build folder you committed to git is never offered, and before clearing, Sparewise tells you which open programs still use those files.

What it finds

  • Developer caches: npm, pnpm, Yarn, pip, uv, conda, Cargo, Go, Gradle, Maven, NuGet and more
  • AI: Ollama, LM Studio and Hugging Face models one by one, with when each was last used and old versions, plus the caches of AI coding tools
  • Projects: node_modules, virtual environments and build folders, idle projects worth hibernating, and packages stored again in many projects
  • Editors and apps: old VS Code, Cursor, Windsurf and Antigravity extensions, and installers apps keep after updating
  • Docker and WSL disks, which never shrink by themselves
  • Windows: temporary files, update leftovers, old installers, browser caches
  • Your own files: large videos, duplicates and forgotten folders, reported only and never removed by Sparewise

Safe by design

  • Scanning changes nothing.
  • It asks before every change.
  • Only caches that rebuild by themselves are offered, each checked by a tested safety rule.
  • It never empties your Recycle Bin, so you decide when space is really released.
  • Private: nothing about your PC is ever sent anywhere.

For AI assistants

Sparewise is also an MCP server. Claude, Cursor, VS Code, Claude Code and Codex can ask why your drive is full and plan a cleanup, and they can apply it only within limits you set, never permanently. Connect them in the app (Settings → Connect AI assistants) or from a terminal:

claude mcp add sparewise -- npx -y sparewise mcp

Questions people ask

Is it free?

Yes, everything is free today, with no account and no ads. Later versions may add paid features; anything you already have keeps working.

Why is it not open source?

It is closed source for now. What you are trusting it with is your files, so the safety rules are written down in plain words: see how it decides what is safe. What it removes goes to the Recycle Bin or an undo window, so a mistake can be put back.

Does it send anything anywhere?

No. No telemetry, no analytics, no account. It goes online only when you ask it to check for updates. See the privacy page.

Mac or Linux?

Windows 10 and 11 only for now.

Why does Windows warn when I run it?

It is new and not code-signed yet. See the first time you run it.

The first time you run it

From the Microsoft Store there is no warning. With the direct installer, Windows may show "Windows protected your PC". That is because Sparewise is new and not code-signed yet, not because anything was found in it. Choose More info, then Run anyway. It installs for your account only and needs no administrator rights.

Want to check the download first? Each release lists SHA-256 checksums. In PowerShell: Get-FileHash .\Sparewise-win-Setup.exe

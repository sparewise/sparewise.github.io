AI models are filling my drive

Short answer: Each local model is several gigabytes, and tools keep every version you have tried. Hugging Face also keeps a download cache that can hold the same model twice.

By hand

  • Ollama: ollama list, then ollama rm <name>
  • LM Studio: My Models, then delete
  • Hugging Face: huggingface-cli delete-cache

With Sparewise

  • Lists every model one by one: its size, which tool it belongs to, and when it was last loaded.
  • Gives each tool's own remove command. Models are your call, so Sparewise never removes one by itself.
  • "Can it come back?" tells you which models can be downloaded again and which exist only on this PC.

How to find duplicate files on Windows

Short answer: Duplicates are common in Downloads, photo folders and phone backups. A duplicate finder compares file contents, not just names, so two files with the same name are not mixed up. Always keep at least one copy and check before removing.

By hand, with Windows' own tools

  1. Windows has no built-in duplicate finder. Sorting a folder by Name and Size in File Explorer shows obvious copies such as "photo (1).jpg".
  2. Check that two files really are the same: same size is not enough; open both or compare their contents.
  3. Keep the copy in the folder you use; remove the others to the Recycle Bin, so you can restore one if needed.

Questions

Can I trust file names to find duplicates?

No. Different files can share a name, and copies can have different names. Comparing contents is the reliable way.

What about photos synced to OneDrive?

OneDrive can keep a copy online and on the PC. Use Files On-Demand instead of deleting; see the OneDrive guide.
